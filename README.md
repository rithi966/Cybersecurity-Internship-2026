# Elevance Skills Cybersecurity Internship 2026

## Overview

This repository contains the projects, reports, documentation, and practical assignments completed during my **Elevance Skills Cybersecurity Internship 2026**. The internship focuses on developing practical cybersecurity skills through hands-on labs, secure software development, vulnerability assessment, web application security, penetration testing, and technical documentation.

Each task is maintained in a separate folder with its own source code, documentation, reports, screenshots, and supporting files.

---

## Internship Tasks

### ✅ Task 1 – Identity and Access Management (IAM) Solution
**Status:** Completed

Designed an Identity and Access Management (IAM) solution for a business environment covering:

- User lifecycle management
- Authentication
- Authorization
- Role-Based Access Control (RBAC)
- Access governance
- Business alignment
- Security recommendations

---

### ✅ Task 2 – TryHackMe Style Cybersecurity Lab
**Status:** Completed

Designed and developed a hands-on cybersecurity learning lab using PHP and MySQL that teaches secure web authentication, web application security, and secure coding practices.

#### Features

- User Login System
- Session Management
- Authorization
- Student Management Portal
- Challenge-Based Learning
- Secure Login using Prepared Statements
- SQL Injection Prevention Concepts
- Documentation and Learning Material

#### Challenges

- Challenge 1 – Introduction
- Challenge 2 – SQL Injection Authentication Bypass
- Challenge 3 – Secure Authentication
- Challenge 4 – Broken Access Control (IDOR)
- Challenge 5 – Secure Coding Review
