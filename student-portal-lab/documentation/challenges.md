# Student Portal Cyber Security Lab

## Introduction

This lab provides hands-on experience with web application security concepts.

Learners will analyze a vulnerable student portal application and understand how secure coding practices protect web applications.

---

# Learning Objectives

By completing this lab, learners will be able to:

- Understand authentication mechanisms
- Understand authorization controls
- Identify SQL Injection risks
- Identify Broken Access Control (IDOR)
- Compare vulnerable and secure code
- Apply secure coding practices

---

# Difficulty Level

Beginner to Intermediate

---

# Required Knowledge

Learners should understand:

- Basic HTML
- Basic PHP
- SQL fundamentals
- Web application concepts

---

# Lab Environment

Technology:

- PHP
- MySQL
- XAMPP
- Bootstrap

Environment:

Localhost web application

---

# Challenges Included

## Challenge 1

Introduction to the application environment.

## Challenge 2

SQL Injection Authentication Bypass.

Analyze the vulnerable login page, identify the SQL Injection vulnerability, understand how authentication can be bypassed, and recommend secure authentication using prepared statements.

## Challenge 3

Secure authentication and SQL Injection prevention.

## Challenge 4

Broken Access Control (IDOR).

Analyze how student records are accessed using URL parameters, determine whether unauthorized records can be viewed, identify the Broken Access Control vulnerability, and recommend proper authorization checks.

## Challenge 5

Secure Coding Review.

Review the provided PHP login code, identify multiple security weaknesses, compare it with the secure implementation developed in this lab, and recommend secure coding best practices.

---

# Completion Criteria

Learners successfully complete the lab when they can:

- Explain authentication flow
- Explain authorization flow
- Identify SQL Injection vulnerabilities
- Identify Broken Access Control (IDOR)
- Review insecure PHP code and identify security weaknesses
- Recommend secure coding improvements
- Describe SQL Injection prevention methods
- Explain how secure authentication protects web applications
