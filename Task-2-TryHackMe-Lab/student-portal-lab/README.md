# Student Portal Cyber Security Lab

## Project Description

This project is a TryHackMe-style cybersecurity learning lab.
It teaches web application security concepts using a PHP and MySQL student portal.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- XAMPP

## Setup Instructions

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project inside:

C:\xampp\htdocs\

4. Create the database in phpMyAdmin.
5. Open:

http://localhost/student-portal-lab/

## Challenges

### Challenge 1
Introduction to the lab environment.

### Challenge 2
Understanding authentication and login process.

### Challenge 3
Secure authentication and SQL Injection prevention.

### Challenge 4
Authorization and access control.

### Challenge 5
Secure coding review.

## Security Concepts Covered

- Authentication
- Authorization
- SQL Injection prevention
- Prepared statements
- Session management
- Secure coding practices

## Learning Outcomes

After completing this lab, learners will be able to:

- Understand how user authentication works in web applications.
- Explain the difference between authentication and authorization.
- Analyze login implementations for common security weaknesses.
- Describe how prepared statements help reduce SQL Injection risk.
- Apply secure coding practices when developing PHP web applications.
- Understand the importance of session management and access control.
